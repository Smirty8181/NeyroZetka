# НейроЗетка

Автономная desktop-панель ИИ-соведущей на Python/PySide6. Озвучка выполняется внешним JeetBot: приложение отправляет короткие ответы от имени Twitch-бота в чат. Настройки хранятся в локальном `config.json` рядом с EXE, память — в `%APPDATA%\NeyroZetka\memory.db`. Конфигурация может содержать OAuth/API-токены и не должна публиковаться; `config.json`, настройки редактора и содержимое `build\` / `dist\` исключены из Git.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python app.py
```

В «Подключениях» укажите канал, логин бота и OAuth token Twitch. В «ИИ и Модели» добавьте Groq key. Ответы на Twitch-сообщения и голос запускаются только после обращения: `НейроЗетка`, `Зеточка`, `Зетка`, `neyrozetka`.

Во вкладке «Зрение и Слух» выберите микрофон и нажмите «Включить микрофон». Это режим постоянного фонового прослушивания параллельно с трансляцией: приложение ждёт начало речи по уровню сигнала, сохраняет короткий pre-roll и фразу до естественной паузы (до 8 секунд), убирает тишину и нормализует громкость перед отправкой в Groq Whisper. Последняя распознанная фраза и история фраз отображаются в блоке «Распознанная речь», а также в живом чате строкой «Вы (голос)». Ответ генерируется в отдельном потоке, поэтому микрофон не ждёт завершения ответа. Фразы без обращения только отображаются и не отправляются в LLM или Twitch.

Пустые ключи не отправляются в API. В режиме Groq Gemini не вызывается; режим `Auto` разрешает fallback Groq → Gemini.

## Сборка удобного EXE

Запустите PowerShell в папке проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build_exe.ps1
```

Готовый переносимый комплект появится в `dist\`: `NeyroZetka.exe` и связанный `config.json`. Установка Python для запуска EXE не требуется.

## Twitch OAuth

Для IRC-токена создайте приложение в Twitch Developer Console и используйте токен с правом `chat:read` и `chat:edit`. EventSub и OAuth браузер можно подключить через отдельный OAuth reverse-proxy без изменения локальной БД: поля уже хранятся в едином `settings`-хранилище.

## OBS и overlay

Включите OBS WebSocket v5, укажите URL/пароль и источник. Предпросмотр и frame grabber подключаются через OBS WebSocket; озвучка внутри приложения намеренно отсутствует.

## Безопасность

Токены сохраняются локально в SQLite для удобства. Для production-развёртывания рекомендуется шифровать значения через Windows Credential Manager или DPAPI. Персонаж по умолчанию остаётся дерзким, но не содержит травли защищённых групп или угроз.
